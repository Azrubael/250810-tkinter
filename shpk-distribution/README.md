Цей скріпт призначений скоротити час на підготовку двох типів звітів.
Після його запуску, з'явиться вікно, в якому порібно буде обрати вхідний файл `xlsx` розподілу особового складу. Потрібно переконатись, що обрано саме правильний файл ШПС, бо існує лише вбудована перевірка назви аркуша `ШПС`.
Так само при обранні прототипу звіту розподілу особового складу, потрібно переконатись, що цей файл може бути прототипом, бо існує лише перевірка назви аркуша `3БО`.

Коротка пам'ятка щодо генерації бінарного файлу зі скрипта Python:
pip install pyinstaller
pyinstaller --onefile --noconsole main.py
